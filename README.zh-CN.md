# Black Hole Horizon

[English](README.md) | [简体中文](README.zh-CN.md)

探索黑洞。体验相对论。

这是一套以 GPU 光子积分为核心的 Three.js/WebGL2 沉浸式体验。首个版本聚焦
史瓦西黑洞、引力透镜、事件视界阴影、光子环结构、程序化吸积盘、多普勒集束
和引力红移。

## 快速开始

```bash
npm install
npm run dev
```

在较新版本的桌面版 Chrome、Edge 或 Firefox 中打开命令行输出的本地地址。如需
构建生产版本，请运行：

```bash
npm run build
npm run preview
```

## 科学说明

### 1. 距离使用引力半径

项目使用引力半径 `r_g = GM/c²` 表示距离。对黑洞来说，`r_g` 把质量与引力强度
封装成一个自然长度单位，因此不必在每条公式中都写出米、千克这样的单位，就能
描述同一套几何规则。

在可视化场景中，世界空间的一个单位就是 `1 r_g`。因此 HUD 显示的是
`42.00 r_g` 这类距离，而不是千米或光秒。改变界面中显示的太阳质量并不需要重建
几何体；它只改变同一个归一化场景对应的物理尺度。

### 2. 事件视界与光子球

本项目使用史瓦西黑洞，也就是不旋转且具有球对称性的黑洞。它的事件视界位于
`2 r_g`。简单来说，光一旦越过这个边界，就不再存在能回到遥远宇宙的向外路径；
着色器也会把这种穿越视为捕获，并让对应方向呈现黑色。

`3 r_g` 处是光子球。在这里，光可以临时绕黑洞运动。附近的光线也可能先绕行
一圈或多圈，再逃向远方。GPU 光线积分器会模拟这种行为，因此画面中会出现黑色
阴影，以及阴影边缘附近纤细明亮的光子环。

### 3. 程序化吸积盘

吸积盘由围绕黑洞螺旋运动的物质组成。越靠近内部的物质通常运动越快、温度越高；
湍流则会形成丝状结构和密度起伏。渲染器没有模拟完整的等离子体流动，而是把这些
趋势组合成一个可视化吸积盘。

默认吸积盘的范围是 `6 r_g` 到 `24 r_g`。着色器会让颜色随外向递减的温度分布
变化，用湍流密度调整亮度和结构，并让盘上物质按类似轨道的角速度旋转。它还应用
了两种相对论效应：

- **多普勒集束与色移：**朝向观察者运动的物质更亮、更偏蓝；远离观察者运动的
  物质更暗、更偏红。
- **引力红移：**来自更深层引力阱的光会发生红移并变暗，使最内侧可见物质与较冷
  的外侧盘面呈现出不同外观。

### 4. 坐标时间与固有时间

广义相对论预言，处在引力场更深处的时钟，相对于遥远处的坐标时间走得更慢。因此
这个体验同时显示两个时钟：坐标时间和固有时间。

固有时间读数使用相机当前半径处的简化静态观察者因子推进。它能传达引力时间
膨胀的概念，但并不是完整的自由落体世界线计算，也没有建模飞行路径的速度、加速度
或精确相对论运动。
